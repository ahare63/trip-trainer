# Card icons

All emojis designed by [OpenMoji](https://openmoji.org/) – the open-source emoji and icon project. License: [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

These are the unmodified “black” outline SVGs from OpenMoji 15.1.0, one file per hexcode. The app recolours them and combines some (an item under a no sign, a number with a price tag) when it draws them; those adapted versions are shared under the same license. This license applies to the files in this folder, not to the rest of the repository (MIT).
